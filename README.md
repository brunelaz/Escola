# Atividades e Projetos Escolares

Este repositório funciona como um portfólio acadêmico contínuo. Ele reúne todos os exercícios, códigos e trabalhos desenvolvidos durante as aulas do curso técnico integrado em Desenvolvimento de Sistemas no IFSP.

## 📂 Conteúdos do Repositório

- **Listas de Exercícios:** Algoritmos, estruturas de dados e códigos de fixação de lógica de programação.
- **Atividades Práticas:** Exercícios de laboratório focados no uso de ferramentas (como terminal e versionamento).
- **Projetos Acadêmicos:** Trabalhos avaliativos mais complexos, desenvolvidos individualmente ou em grupo.

## 💻 Tecnologias e Ferramentas
- C
- Python
- HTML
- CSS
- JavaScript
